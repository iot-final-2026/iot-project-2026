# 요구사항 정의서


## 1. 프로젝트 목적

본 프로젝트는 컨베이어벨트를 활용하여 초콜릿과 사탕을 자동으로 분류 및 포장하는 시스템을 개발하는 것을 목표로 한다.

적외선 센서와 카메라를 이용하여 제품을 감지 및 분류하고, 생산량을 실시간으로 관리하며, 박스가 가득 차면 자동 배출 및 알림 기능을 수행한다. 또한 작업자용 LCD와 관리자용 웹 모니터링 시스템을 구축하여 생산 현황을 효율적으로 관리하고, 생산 공정의 자동화와 작업 효율성을 향상시키는 것을 목적으로 한다.


## 2. 사용자 구분

| 사용자 | 설명                                   | 접근 권한                                                                        |
| ------ | -------------------------------------- | -------------------------------------------------------------------------------- |
| 작업자 | 생산 라인에서 시스템을 운영하는 사용자 | 작업자용 LCD 화면 이용, 생산량 확인, 컨베이어 제어, 알림 확인                    |
| 관리자 | 생산 공정 및 시스템을 관리하는 사용자  | 관리자 웹 페이지 이용, 실시간 모니터링, 생산 통계 조회, 분류 결과 및 데이터 관리 |


## 3. 기능 요구사항

|:---:|------|------------|------------|:------:|
| FR-01 | 회원 | 로그인 | 작업자 및 관리자는 아이디와 비밀번호를 입력하여 로그인한다. | 높음 |
| FR-02 | 회원 | 로그아웃 | 로그인한 사용자는 시스템에서 로그아웃할 수 있다. | 중간 |
| FR-03 | 회원 | 권한 구분 | 로그인한 계정의 권한(작업자/관리자)에 따라 접근 가능한 화면과 기능을 구분한다. | 높음 |
| FR-04 | 센서 | 물체 감지 | 적외선 센서를 이용하여 컨베이어벨트 위의 물체를 감지한다. | 높음 |
| FR-05 | 카메라 | 이미지 촬영 | 물체가 감지되면 카메라로 이미지를 촬영한다. | 높음 |
| FR-06 | AI/OpenCV | 물체 분류 | 촬영된 이미지를 OpenCV를 이용하여 초콜릿과 사탕을 분류한다. | 높음 |
| FR-07 | 컨베이어 | 라인 제어 | 컨베이어벨트의 시작, 정지 및 속도를 제어한다. | 높음 |
| FR-08 | 분류 | 자동 분류 | 분류 결과에 따라 제품을 해당 포장 위치로 이동시킨다. | 높음 |
| FR-09 | 생산 | 박스 적재 완료 감지 | 박스에 설정된 개수만큼 제품이 적재되면 포장 완료 상태를 감지한다. | 높음 |
| FR-10 | 생산 | 생산량 집계 | 초콜릿과 사탕의 생산량 및 세트 수를 실시간으로 집계한다. | 높음 |

| FR-13 | 작업자 UI | 이상 감지 알림 | 센서 오류 또는 컨베이어 이상 발생 시 LCD, LED, 부저를 통해 작업자에게 경고를 제공한다. | 높음 |
| FR-14 | 관리자 웹 | 실시간 모니터링 | 관리자 페이지에서 생산 현황과 컨베이어 상태를 실시간으로 확인한다. | 높음 |
| FR-15 | 관리자 웹 | 분류 결과 확인 | 촬영된 이미지와 초콜릿·사탕 판별 결과 및 신뢰도(%)를 표시한다. | 높음 |
| FR-16 | 관리자 웹 | 생산 통계 | 목표 생산량과 실제 생산량을 그래프로 시각화한다. | 중간 |
| FR-17 | 데이터 | 생산 데이터 저장 | 촬영 이미지, 분류 결과, 생산량 데이터를 데이터베이스에 저장한다. | 중간 |

## 5. 제외사항

- 로봇팔을 이용한 제품 이송 및 적재 기능은 구현 대상에서 제외한다.
- 제품을 자동으로 분류한 이후의 밀봉·포장 공정은 구현 대상에서 제외한다.
- 원격 제어 및 모바일 애플리케이션 기능은 구현 대상에서 제외한다.
- 사용자 회원가입 및 계정 관리 기능은 구현 대상에서 제외하며, 사전에 등록된 작업자 및 관리자 계정을 사용한다.
- 무게센서를 이용한 분류 기능은 구현 대상에서 제외한다.
