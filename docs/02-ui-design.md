
# 자동 분류 및 작업자 포장 알림 시스템 UI 디자인

![UI_작업자_초안](./UI_작업자_초안.png)
![UI_관리자_초안](./UI_관리자_초안.png)

## 1. 문서 목적

본 문서는 초콜릿·사탕 자동 분류 시스템의 작업자용 화면과 관리자용 웹 화면의 UI 구성을 정리한 문서이다.

- 작업자 화면: 생산 현황 확인 및 라인 제어 중심
- 관리자 화면: 생산 모니터링, 통계, 이미지, 알람, 장비 상태 관리 중심

---

# 2. 작업자 화면

## 2.1 화면 개요

- 화면 형태: 가로형 작업자 전용 화면
- 주요 목적:
  - 현재 생산량과 목표량 확인
  - 초콜릿·사탕 생산 진행률 확인
  - 라인 속도 조절
  - 생산 시작 및 정지
  - 작업자 정보와 연결 상태 확인

## 2.2 상단 영역

- 현재 날짜
- 현재 시간
- 시스템명
- 로그인한 작업자 이름
- 서버 또는 장비 연결 상태
- 알림 아이콘

## 2.3 초콜릿 생산 현황

- 제품명: 초콜릿
- 박스 기준: 1박스 = 10개
- 현재 생산 개수
- 현재 완료 박스 수
- 목표 생산 개수
- 목표 박스 수
- 진행률
- 진행률 바

예시:

```text
초콜릿
1박스(10개)

현재 108개 / 10박스
목표 200개 / 20박스
진행률 50%
```

## 2.4 사탕 생산 현황

- 제품명: 사탕
- 박스 기준: 1박스 = 1개
- 현재 생산 개수
- 현재 완료 박스 수
- 목표 생산 개수
- 목표 박스 수
- 진행률
- 진행률 바

예시:

```text
사탕
1박스(1개)

현재 8개 / 8박스
목표 100개 / 100박스
진행률 8%
```

## 2.5 라인 제어 영역

- 현재 라인 속도
- 속도 감소 버튼
- 속도 증가 버튼
- 시작 버튼
- 정지 버튼

동작:

- `-` 버튼: 라인 속도 감소
- `+` 버튼: 라인 속도 증가
- `시작`: 생산 라인 가동
- `정지`: 생산 라인 정지

## 2.6 작업자 화면 구성 우선순위

1. 현재 생산량
2. 목표 생산량
3. 완료 박스 수
4. 진행률
5. 라인 속도 및 시작·정지
6. 작업자 정보
7. 연결 상태 및 알림

# 3. 관리자 화면

## 3.1 화면 개요

- 화면 형태: 기본 데스크톱 크기의 웹 대시보드
- 주요 목적:
  - 실시간 생산 현황 모니터링
  - 제품 분류 이미지 및 신뢰도 확인
  - 생산 통계 확인
  - 알람 및 이상 내역 확인
  - 장비 상태 확인
  - 생산 목표 설정

## 3.2 상단 영역

- 시스템명
- 관리자 계정
- 계정 메뉴

## 3.3 좌측 메뉴

- 대시보드
- 제품 이미지
- 알람/이상 내역
- 생산 현황
- 생산 통계
- 장비 상태
- 설정
- 작업자별 정보

- 사탕 목표선

## 4.3 제품 분류 비율

- 초콜릿 비율
- 사탕 비율
- 도넛 차트 사용

## 4.4 최근 제품 분류 이미지

- 분류 신뢰도

## 4.5 최근 알람 및 이상 내역

- 알람 종류
- 알람 내용
- 발생 시각
- 심각도 또는 상태

## 4.6 장비 상태

- 적외선 센서
- 카메라
- 서보모터
- 컨베이어
- LCD
- 상태: 정상 / 오류 / 점검

## 4.7 생산 목표 설정

- 초콜릿 목표 수량
- 사탕 목표 수량
- 저장 버튼

# 6. 화면 흐름

## 작업자 화면

```text
시작
→ 작업자 로그인
→ 안내문 확인
→ 작업자 메인 화면
→ 생산 시작
→ 생산 현황 확인 및 라인 제어
→ 생산 종료
→ 로그아웃
```

## 관리자 화면

```text
관리자 로그인
→ 대시보드
→ 생산 현황 및 통계 확인
→ 제품 이미지 확인
→ 알람 및 장비 상태 확인
→ 생산 목표 설정
→ 로그아웃
```
