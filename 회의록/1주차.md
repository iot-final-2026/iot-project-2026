### 주제

**컨베이어벨트를 활용한 자동 분류 및 포장 시스템 구축**

### 초기 아이디어

* **전체 감지:** 적외선 감지 센서
* **캔:** 금속 감지 센서

#### 2차 아이디어

* 분류 방식

  * 칸막이를 이용한 분류
  * 컨베이어벨트 끝의 수거통 이동 방식
* 카메라 촬영 후 데이터를 DB에 저장
* 로봇팔을 이용하여 감지된 물체를 지정된 위치로 이동
* 작업 상태 및 주의사항 알림 기능 제공

---

## 2. 최종 프로젝트 방향

### 프로젝트 구성

초콜릿 및 사탕을 자동으로 분류하고 포장하는 시스템으로 진행하기로 결정.

### 동작 순서

1. 초콜릿(또는 사탕)을 컨베이어벨트에 투입
2. 적외선 센서로 물체 감지
3. 카메라로 이미지 촬영 및 분류
4. 분류 위치로 이동
5. 무게 측정 및 상태 알림
6. 로봇팔을 이용해 지정된 위치로 이동 및 포장

### 주요 기능

* 데이터베이스(DB) 설계
* 사용자 UI 구현
* 초콜릿/사탕을 **n개 단위(1 Set)** 로 포장
* 포장 상자가 가득 찼을 경우

  1. 알림 신호 출력
  2. 가림막을 이용해 최대 2곳으로 분류
  3. 로봇팔을 이용해 상자 밀기
  4. 새 상자 자동 배치
* 불량품 감지
* 적외선 센서 및 무게 센서 활용

## 4. 결정 사항

* 프로젝트 주제를 **재활용품 분류 시스템**에서 **초콜릿/사탕 자동 분류 및 포장 시스템**으로 변경한다.
* 카메라, 적외선 센서, 무게 센서, 로봇팔을 연동하여 자동 분류 및 포장을 구현한다.
* 촬영 데이터는 데이터베이스에 저장하고, UI를 통해 상태를 확인할 수 있도록 개발한다.
