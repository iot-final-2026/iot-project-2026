## 2026년 7월 29일 수요일

### 장비 검수

- `IMX219 8MP CSI 카메라`의 연결 상태와 영상 출력 여부를 점검하였다.
- `컨베이어 벨트`는 기존에 보유한 모터 드라이버로 구동이 가능한지 검수 중이다.
- 검수 결과에 따라 기존 모터 드라이버를 계속 사용할지, 새로운 모터 드라이버를 구매할지 결정하기로 하였다.

#### 카메라 연결 문제 해결

- `rpicam-hello --list-cameras` 실행 시 `No cameras available` 메시지가 출력되며 카메라가 인식되지 않는 문제가 발생하였다.
- `/boot/firmware/config.txt`에 IMX219 카메라 설정을 추가한 후 시스템을 재부팅하였다.

    ```txt
    camera_auto_detect=0
    dtoverlay=imx219,cam0
    ```

#### 카메라 초점 문제 해결

- 카메라 실행 결과 영상은 정상적으로 출력되었으나, 초점이 맞지 않아 촬영 대상이 흐리게 보이는 문제가 발생하였다.
- 카메라 렌즈를 회전하여 초점을 조절한 결과, 물품이 선명하게 촬영되는 것을 확인하였다.
- 초점 조절 후 카메라의 영상 출력 및 촬영 기능이 정상적으로 작동하였다.

### 환경 세팅

- Raspberry Pi Imager를 이용하여 SD 카드에 Debian GNU/Linux 13.6 (Trixie) 운영체제를 설치하였다.
- 설치된 운영체제의 버전과 라즈베리파이의 정상 부팅 여부를 확인하였다.

#### 한글 입력 문제 해결

- Wayland 환경에서 IBus 한글 입력이 동작하지 않아 입력기를 Fcitx5로 변경하였다.
- 설정 후 터미널과 Chromium에서 한글 입력이 정상적으로 작동하는 것을 확인하였다.
