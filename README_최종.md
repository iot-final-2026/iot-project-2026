# 🍫 초콜릿·사탕 자동 분류 및 생산 모니터링 시스템

## 1. 프로젝트 개요

### 1.1 프로젝트 소개

본 프로젝트는 컨베이어벨트를 기반으로 초콜릿과 사탕을 자동으로 감지하고 분류하며, 제품의 생산량을 실시간으로 관리할 수 있는 **IoT 기반 자동 생산 시스템**이다.

적외선 센서를 이용하여 컨베이어벨트 위의 제품을 감지하고, 카메라를 통해 제품 이미지를 촬영한 후 OpenCV 기반의 이미지 분류 기능을 이용하여 초콜릿과 사탕을 자동으로 구분한다.

분류된 제품은 컨베이어벨트를 통해 각각의 포장 위치로 이동하며, 설정된 수량만큼 제품이 적재되면 박스 적재 완료를 판단하고 서보모터를 이용하여 박스를 배출한다.

또한 작업자용 LCD 화면에서는 현재 생산량, 목표 생산량, 완료 세트 수 및 장비 상태를 확인할 수 있으며, 관리자용 웹 페이지에서는 생산 현황, 제품 분류 결과, 생산 통계, 알람 및 장비 상태를 실시간으로 확인할 수 있도록 구성한다.

---

### 1.2 개발 배경 및 필요성

기존의 생산 및 포장 공정에서는 제품의 분류와 수량 확인을 작업자가 직접 수행하는 경우가 많아 반복적인 작업에 많은 인력이 필요하다.

특히 제품의 종류가 다양해질수록 작업자의 판단에 의존한 수작업 분류 과정에서 다음과 같은 문제가 발생할 수 있다.

- 제품 분류 과정에서의 작업자 실수
- 생산량 및 포장 수량 확인에 필요한 시간 증가
- 생산 현황을 실시간으로 확인하기 어려움
- 장비 이상 발생 시 즉각적인 대응 어려움
- 생산 데이터를 체계적으로 기록하고 관리하기 어려움

이러한 문제를 해결하기 위해 센서, 카메라, 컨베이어벨트, 마이크로컨트롤러 및 서버를 연동하여 제품의 감지부터 분류, 생산량 집계, 박스 배출 및 모니터링까지 자동화하는 시스템을 개발한다.

### 2.7.5 박스 적재 및 완료 처리

제품이 분류된 후 각각의 제품은 지정된 포장 위치로 이동한다.

초콜릿은 10개를 하나의 세트로 관리하며, 사탕은 1개를 하나의 세트로 관리한다.

예를 들어 초콜릿 생산량이 10개에 도달하면 초콜릿 1세트가 완료된 것으로 처리한다.

```text
초콜릿

제품 1
제품 2
제품 3
...
제품 10
   ↓
1세트 완료
   ↓
박스 적재 완료
   ↓
서보모터 동작
   ↓
박스 배출
   ↓
LED / 부저 / LCD 알림

박스가 가득 찬 경우 작업자에게 박스 교체가 필요하다는 알림을 제공한다.
```

### 2.7.6 오류 및 알림 처리

시스템에서 오류가 발생하면 오류 유형과 발생 위치를 확인하고 ALERTS 테이블에 기록한다.

예를 들어 다음과 같은 오류가 발생할 수 있다.

```text
적외선 센서 오류
카메라 연결 오류
이미지 분류 실패
컨베이어 오류
서보모터 오류
서버 연결 오류
데이터베이스 연결 오류
오류가 발생하면 작업자 화면에서는 LED와 부저를 이용하여 즉시 알림을 제공하고 LCD 화면에 오류 내용을 표시한다.

관리자는 관리자 웹 페이지에서 발생한 오류의 종류, 발생 시간, 관련 장비 및 처리 상태를 확인할 수 있다.
```

## 3. 개발환경 구축


### 3.1 개발환경 개요

본 프로젝트는 IoT 장비, Backend Server, 이미지 처리 서버, 데이터베이스, 작업자 UI 및 관리자 Web을 각각 분리하여 개발한다.

각 구성요소는 API를 통해 데이터를 주고받도록 구성하여 시스템 간 결합도를 낮추고 유지보수성을 높인다.

### 3.2 개발환경

```text
구분	사용 기술
작업자 UI	WPF
Backend	ASP.NET Core
이미지 처리	FastAPI
이미지 처리 라이브러리	OpenCV
데이터베이스	MySQL
```

### 4.3 적외선 센서 감지 기능 개발

컨베이어벨트 위로 제품이 지나갈 때 적외선 센서를 이용하여 제품의 존재 여부를 감지한다.

센서에서 제품이 감지되면 카메라 촬영을 요청하고 이후 이미지 분류 과정을 진행한다.

```text
센서 대기
   ↓
제품 감지
   ↓
감지 신호 발생
   ↓
카메라 촬영 요청

테스트 항목
제품이 없을 때 오작동 여부
제품 투입 시 정상 감지 여부
연속 제품 감지 여부
센서 연결 오류 여부
```

### 4.4 카메라 촬영 기능 개발

적외선 센서가 제품을 감지하면 카메라를 통해 제품 이미지를 촬영한다.

촬영된 이미지는 이미지 분류 서버로 전달한다.

촬영 이미지에는 제품 분류 시간 등의 정보를 연결하여 데이터 추적이 가능하도록 구성한다.

### 4.5 이미지 분류 기능 개발

촬영된 제품 이미지는 FastAPI 서버를 통해 전달되고 OpenCV를 이용하여 이미지 처리를 수행한다.

이미지 처리 결과를 바탕으로 제품을 초콜릿 또는 사탕으로 분류한다.

```text
Camera
  ↓
Image
  ↓
FastAPI
  ↓
OpenCV
  ↓
Image Processing
  ↓
Classification
  ↓
Chocolate / Candy
  ↓
Confidence
```

분류 결과에는 다음 정보가 포함된다.

```text
제품 종류
분류 신뢰도

분류 시간
분류 성공 여부
```

### 4.6 자동 분류 기능 개발

AI 분류 결과에 따라 제품을 해당 위치로 이동시킨다.

예를 들어 분류 결과가 초콜릿이면 초콜릿 적재 위치로 이동시키고, 사탕이면 사탕 적재 위치로 이동시킨다.

```text
제품 감지
   ↓
이미지 촬영
   ↓
AI 분류
   ↓
 ┌───────────────┐
 │               │
초콜릿          사탕
 │               │
 ↓               ↓
초콜릿 위치     사탕 위치
```

### 4.7 생산량 집계 기능 개발

제품이 정상적으로 분류되면 제품 종류에 따라 생산량을 증가시킨다.

초콜릿은 개별 수량과 세트 수량을 함께 관리한다.

```text
초콜릿 생산량 = 초콜릿 개별 제품 수
초콜릿 세트 수 = 초콜릿 생산량 / 10
```

사탕은 1개를 1세트로 관리한다.

```text
사탕 생산량 = 사탕 개별 제품 수
사탕 세트 수 = 사탕 생산량
```

생산량 데이터는 생산 세션별로 관리하며 데이터베이스에 저장한다.

### 4.8 박스 완료 및 배출 기능 개발

초콜릿의 경우 10개가 적재되면 하나의 박스 또는 세트가 완료된 것으로 처리한다.

박스가 완료되면 서보모터를 동작시켜 박스를 배출하고 작업자에게 알림을 제공한다.

```text
10개 도달?
   ↓
YES
   ↓
세트 완료
   ↓

   ↓
박스 배출
   ↓
LED / 부저 / LCD 알림
```

# 7. 트러블 슈팅

### 7.1 센서 중복 감지 문제

```text
문제
제품 하나가 센서를 통과할 때 센서 신호가 여러 번 발생하여 제품 수량이 실제보다 많이 증가하는 문제가 발생하였다.

원인
센서가 제품을 감지하는 동안 짧은 시간 동안 여러 번 신호가 발생하는 현상이 발생하였다.

해결
센서가 한 번 감지된 이후 일정 시간 동안 추가 감지를 무시하는 방식으로 중복 감지를 방지하였다.
```

```text
센서 감지
   ↓
제품 처리
   ↓
일정 시간 Lock
   ↓
센서 재감지 허용

결과
제품 하나당 하나의 생산 데이터가 생성되도록 수정하였다.
```

### 7.2 카메라 촬영 타이밍 문제

```text
문제
센서가 제품을 감지한 직후 카메라를 촬영하면 제품이 카메라 위치에 도달하기 전에 촬영되어 제품 이미지가 제대로 나오지 않는 문제가 발생하였다.

원인
센서 위치와 카메라 위치 사이에 물리적인 거리가 존재하였다.

해결
센서 감지 후 일정 시간 지연을 적용하여 제품이 카메라 촬영 위치에 도달한 후 촬영하도록 수정하였다.
```

```text
센서 감지
   ↓
Delay
   ↓
카메라 촬영
   ↓
이미지 처리

결과
제품이 이미지 중앙에 위치한 상태에서 촬영할 수 있도록 개선하였다.
```
